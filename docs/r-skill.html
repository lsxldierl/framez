Making a Combat Skill

This tutorial takes a sword swing from the first blocked pose to a clip the game can play. By the end you have a saved animation that plays once at Action priority, with its hit frames marked for your scripts and its upper body ready to play over a run.

You need a rig in the place and a new animation open on it, as in your first animation. A video of the move you want is useful but optional.

Set up the Clip

  1. Open the animation settings. They open the Inspector's Clip page, where the clip's length, priority and looping are set.

    Edit ‣ Settings ‣ Animation settings

  2. Type the skill's cast time in Length, for example 0.8s. A bare number counts frames, so 24 makes the clip 24 frames long.

  3. Set Priority to Action. Priority decides which animations the clip plays over in the game, and Action is above Idle and Movement, so the skill shows over a walk or an idle.

  4. Switch off Looping so the skill plays once.

  5. If you have a video of the move, link it before you start posing, as described in Copying a Move from a Video.

Block Out the Poses

  1. Pose the rig on frame 0 in its guard stance. Select a limb in the viewport and drag the rings that appear round it. While Auto key is on, letting go of a handle keys the limb.

  2. Move the playhead to the wind-up, pose the rig again, and give every limb a key on that frame so the pose is complete. Do the same for the frame where the sword lands and for the recovery. Key only these big poses for now.

    Key ‣ Insert key on all limbs

  3. Play the blocking as held poses to judge the rhythm. Stepped preview set to On keys holds each key until the next one. Set it back to Off once the timing works.

    View ‣ Stepped preview ‣ On keys

Fix the Timing and Shape the Moves

  1. Select the keys of the swing by dragging a box round them on the timeline. A box with a handle at each end appears round the selection.

  2. Drag an end of the box to make the swing faster or slower. The keys spread or squeeze toward the other end, and Alt stretches about the middle. See Stretch by dragging.

  3. To give the swing an exact length instead, open Scale keys with the same keys selected, type a length such as 0.4s, and keep the First key fixed.

    Key ‣ Timing ‣ Scale keys...

  4. Select the key where a move starts and press 7 to open Easing. Choose where the move slows, then a style. Slow end with a strong style such as Expo makes a hit land hard. Pointing at a style shows it on the rig before you click.

    Key ‣ Easing

  5. Make the arm trail the body. Select keys on two or more limbs of the arm and run Offset limbs. Each limb's keys land a frame or two after the limb above it, and Frames between in Adjust sets the gap.

    Key ‣ Timing ‣ Offset limbs

  6. Add the in-between poses that give the swing its snap. Press T with the mouse over the viewport to open the Slider, press Shift+B for the Breakdown mode, and move the mouse left or right until the pose reads well. Click to key it.

    Pose ‣ Slider ‣ Open at the cursor

Add Weight

  1. Let the arms keep moving after the body stops. Follow-through makes the head and arms, or the limb you have selected, trail behind what moves them, swing past and settle. Its values open in Adjust at the foot of the Framez window, and dragging a value makes the result again.

    Pose ‣ Physics ‣ Follow-through

  2. Make the head turn a few frames after the body with Overlap. Its Limbs value chooses which parts start late, so set it to the head.

    Pose ‣ Physics ‣ Overlap

  3. If the skill spins, use Pivot rotation to turn the whole body about a foot, a hand or the weapon tip.

    Pose ‣ Physics ‣ Pivot rotation

Keep the Feet Planted

  1. Turn on the Foot sliding overlay. A red mark appears on the events lane wherever a foot that is on the floor slides.

    View ‣ Overlays ‣ Foot sliding

  2. At a red mark, select the foot and run Foot lock. The foot stays where it is over the frames you choose, and the knee bends to keep it there.

    Pose ‣ Physics ‣ Foot lock

  3. To fix every sliding foot in one step, run Fix foot sliding instead.

    Pose ‣ Physics ‣ Fix foot sliding

  4. If the weapon changes hands during the skill, add that now, as described in Picking Up, Passing and Throwing an Object.

Mark the Hit for the Game

  1. Switch to the Game data workspace. Its Game menu holds everything the game reads from the clip.

    View ‣ Windows ‣ Game data

  2. Put the playhead on the first frame where the sword can hurt and add a hit window. A bar appears on the Hit windows row under the rig. Drag its ends to the first and last frame of the hit.

    Game ‣ Hit windows ‣ Add hit window here

  3. Select the bar and fill in its page in the Inspector. Choose the part the hitbox moves with, which is the weapon or the hand, then Box or Ball and its size. Add the fields your script reads, such as Damage 25 or Knockback 30.

  4. For a single moment instead of a range, such as a sound or a spark, move the playhead there and add an event. Type a name such as Sound or SpawnVFX and press Enter.

    Game ‣ Add event here...

Check and Test It

  1. Run Check animation. It lists each problem at its frame, such as sliding feet, a limb that jumps in one frame, a limb that stops dead, a curve that passes its key and comes back, and a limb that goes through the torso. Click a row to go to its frame, and use the row's button to fix it. Fix all runs every fix that needs no choice.

    Key ‣ Clean up ‣ Check animation

  2. See the skill the way the game will play it. Animator preview plays the clip on a see-through copy beside the rig through Roblox's own Animator.

    Game ‣ Animator preview

  3. Check that the skill comes cleanly out of your idle or run. Transition to plays the end of the saved clip you choose and then the skill from its first frame.

    Game ‣ Preview with another clip ‣ Transition to

Save It and Bring It into the Game

  1. If the skill must play while the character runs, set a body mask before you save. With Upper body, the legs play whatever is under the skill, such as the run.

    Game ‣ Body mask ‣ Upper body

  2. Save the animation, then save the place.

    File ‣ Save

  3. Publish the clip so the game can play it. Roblox's upload window opens, and you give Framez the asset id afterwards.

    File ‣ Publish to Roblox...

  4. Add the FramezGameData module to the game, once per game. It turns the hit windows into hits your scripts can react to. The code is on the Hit windows and foot contacts page.

    Game ‣ In the game ‣ Hit windows and foot contacts

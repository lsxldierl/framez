Keyboard Shortcuts

The Keyboard Shortcuts window lists every command with its key and lets you give any command a key of your own. You can search by name, find out what a key does by pressing it, start from a set of keys that suits you, and save your keys in the place so that everyone working in it can use them.

The Keyboard Shortcuts Window

Menu
Edit ‣ Settings ‣ Keyboard shortcuts...
Right-click
A menu row or a Menu search result, then Keyboard shortcuts...

The window opens as a floating window. A search box and a By key button are at the top, the list of commands fills the middle, and the foot holds the Start from button and the Reset all button.

Every command that Menu search knows can take a key, in every workspace, together with the built-in keys that have no menu row, such as Play, the arrow keys and the number pad. The list is grouped like the menus, in the order Timeline, File, Edit, Key, Pose, Face, Scene, Game, View, the Curve editor and Help. The name of a command that sits inside a submenu has the submenu's name in grey in front of it. A command that cannot run at the moment is drawn in grey. After the commands come the fixed keys that work while a tool is busy.

Each row shows the command's name on the left and its keys on the right, one box for each key. A command with no key shows a box with a dash. A row that you changed has an orange dot, orange key boxes, and a Reset button of its own that returns it to the key it started with. Menus and Menu search show your keys beside the commands.

Notes

The keys work while a Framez window is active, so click in the Framez window first. Keys that Studio uses for its own commands still run, and the row says so when you choose one. See Shortcut List for the default keys.

Search Commands

Menu
Edit ‣ Settings ‣ Keyboard shortcuts...

The search box at the top of the window narrows the list as you type. Every word you type must appear in the command's name, in the submenu it belongs to, or in its keys, so "mirror" lists the mirroring commands and "shift" lists everything that uses Shift. When nothing matches, the list says "No command has those words."

Choosing Keyboard shortcuts... from the right-click menu of a command opens the window already searching for that command.

Example

For example, type "play" to find Play / pause and the commands that change the playback speed, then click the key box of the one you want to change.

By Key

Menu
Edit ‣ Settings ‣ Keyboard shortcuts...

By key answers the opposite question to the search box, which is what a given key does. Click the button, then press the keys. The list then shows only the commands that use that combination, and the search box shows the keys you pressed. When no command uses them, the list says that the key does nothing in Framez. Clicking By key again, or typing in the search box, goes back to the full list.

Example

For example, before giving Shift+W to a command, click By key and press it to see whether it already belongs to another one.

Changing a Key

Menu
Edit ‣ Settings ‣ Keyboard shortcuts...

To change a key, click the key box on the command's row, which shows a dash when the command has no key. The box turns orange and reads Press keys. Press the new keys, with any modifiers held, and the command has them at once. Esc cancels without changing anything.

Options

A key that is already taken
The row says which command has it, for example "Shift+W is on Breakdown.", with Replace and Cancel. Replace gives the key to this command and takes it away from the other one.
A key that Studio uses
The change is made, and the row adds a note such as "Studio's Duplicate also runs." because Studio's own command still runs as well.
Keys that cannot be given
Esc, the Windows keys, Menu and Print Screen cannot be given to a command. Esc stays on Select none and cannot be removed from it.

Notes

Keys that work while a tool is busy, keys that are typed into a text field, and the keys of the animation list when no animation is open are never taken over by a command.

Example

For example, to put Play / pause on a key that is easier to reach than the space bar, click its key box and press Q.

Several Keys on One Command

Right-click
A command's row in the window

A command can have more than one key. Right-clicking a row opens a small menu for it.

Options

Change shortcut...
Replaces all of the command's keys with the one you press next.
Add another key...
Gives the command an extra key and keeps the ones it has. The row is greyed for a command with no key, which gets its first key from Change shortcut or by clicking its key box.
Remove shortcut
Takes all of the command's keys away.
Reset shortcut
Appears for a row that was changed. It returns the command to the keys it started with.

Example

For example, keep K on Insert key and use Add another key... to give it I as well, so both habits work.

Start From

Menu
Edit ‣ Settings ‣ Keyboard shortcuts...

Start from replaces the starting point that your changes sit on. The button names the set in use, for example Start from: Framez, and opens a list of sets. Keys that a set does not mention keep the Framez key, unless a key the set uses would take it away.

If you have changed keys already, the choice asks first with a heading that says how many changes you have. Replace them starts over from the new set and drops your changes. Keep them on top starts from the new set and keeps your changes on top of it.

Options

Framez
The default keys, as listed on the Shortcut List page.
Blender
Insert key is I. Delete keys is X or Del. Previous frame and Next frame are Left and Right, and Previous key and Next key are Up and Down. Go to the start and Go to the end are Shift+Left and Shift+Right. Select none is Esc or Alt+A. Redo is Ctrl+Shift+Z or Ctrl+Y. Menu search is F3 or Ctrl+K. Frame selected is Num .. Rotate is R, Move is G, and Isolate is Shift+H. The two Move keys 1 frame commands lose their keys, because their keys now go to the start and end.
Moon Animator 2
Insert key is = or Num +. Previous frame and Next frame are 4 and 6, and Previous key and Next key are J and K, so K moves from Insert key to Next key. Show onion skin is B, taking it from Blink here. Add bookmark here is Num *, and Mirror animation is Ctrl+R.
This place
Sets that were saved in the place with Save mine to this place. They are listed under a This place heading.

Example

For example, an animator who is used to Blender's keys chooses Blender and then moves the few commands that still disagree with their habits, using Keep them on top.

Save Mine to This Place

Menu
Edit ‣ Settings ‣ Keyboard shortcuts...

Save mine to this place... is the last row of the Start from list. It keeps your keys in the place under a name, so that everyone working in it can choose them from the This place part of the list. A small box asks for the Name, and it suggests your Studio account name followed by "'s keys". Click Save, or press Enter, to write the set. Saving again under the same name replaces that set.

The set holds only the keys that differ from the default Framez keys. It is stored in the FramezKeys folder of ServerStorage, so a place that is not saved loses it. Your own keys are stored with Framez's settings on your computer, apart from the sets in the place.

Example

For example, a team that works in one Team Create place can agree on a set of keys, save it once, and let everyone choose it from the list.

Reset All

Menu
Edit ‣ Settings ‣ Keyboard shortcuts...

Reset all returns every key to the set you started from. It asks "Undo your N changes?" with a red Reset all button and Cancel, so it never changes anything by accident. When you have made no changes, the status line says that the keys are the starting set's.

Keys That Depend on the Window

Menu
Edit ‣ Settings ‣ Keyboard shortcuts...

Some commands work only while a particular window is the one receiving the key presses. The commands of the Curve editor are the example. They have their own group in the list, and a key given to one of them is kept for that window alone. The same key can therefore do one thing in the Curve editor and another everywhere else, and a key clashes only with another command of the same window.

Example

For example, A selects every key in the timeline and also selects every key on the shown curves while you work in the Curve editor, because each has its own entry.

Fixed Keys

Menu
Edit ‣ Settings ‣ Keyboard shortcuts...

At the end of the list, the keys that only mean something while a tool is busy are shown without key boxes you can click. They cannot be changed, and they are listed so that you know which keys are taken while a tool is running.

Options

While the slider is open
Enter keeps the result, Esc cancels, Tab goes to the next mode, W switches between world and local, 1 limits the slider to rotation, 2 limits it to position, X, Y and Z choose one axis, and O, P and L open more options.
While drawing a camera path
Enter finishes the path, Esc cancels, and Backspace removes the last point.
While dragging a path key
X, Y and Z keep the drag to one axis.
In the animation list
Enter opens the selected animation, F2 renames it and Del deletes it.
Anywhere
Esc cancels or closes whatever is open.

Change Shortcut

Right-click
Any menu row, or a Menu search result

Change shortcut... gives a single command a key of your own without opening the Keyboard Shortcuts window. Right-click the command in any menu, or in the results of Menu search, and choose it. A small box reads "Press keys for NAME". Press the keys you want, or press Esc to cancel. When the keys already belong to another command, the box names it and offers Replace and Cancel, as the window does.

Options

Add another key...
Gives the command a second key. It is greyed for a command that has no key yet.
Remove shortcut
Takes the command's keys away.
Reset shortcut
Appears for a command that was changed, and returns it to the key it started with.
Keyboard shortcuts...
Opens the Keyboard Shortcuts window with this command already searched for.

Example

For example, right-click Insert key on all limbs in the Key menu, choose Change shortcut... and press Shift+K to give it a key of its own.

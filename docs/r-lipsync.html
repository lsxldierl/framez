Setting up Lip Sync

This tutorial times mouth shapes to a voice line, for a short, a cutscene or an NPC's greeting. At the end the character's mouth moves with the voice and the lip sync is saved with the clip.

You need an animation open on a rig whose head has FaceControls (a dynamic head) or a face Decal (a classic head), and a voice line that the signed-in account may use, either a Roblox sound or a Sound already in the place. Exact timing also needs the Framez Helper, which Installing the Framez Helper explains, and it works best with English.

Put the Voice on the Timeline

  1. Switch to the Scene workspace by clicking the Scene tab at the left of the menus.

    View ‣ Windows ‣ Scene

  2. Add the voice line as a sound. Type its asset id or link, or choose one of the Sounds in the place. The sound gets a row with a block that shows its loudness. See Sound.

    Scene ‣ Add ‣ Sound...

  3. Drag the block to the frame where the line starts. The block snaps to keys and events as it moves.

Prepare the Head

  1. On a classic head, give the head a mouth. This is done once for each character. It adds a Decal named Mouth on the face side of the head, which shows Framez's own mouth shapes at once with nothing to upload. A dynamic head has its own mouth, so this row is greyed for it and nothing needs doing. See Add Mouth Decals.

    Face ‣ Mouth ‣ Add mouth decals

  2. To use your own mouth images on a classic head, select an image for each of the nine shapes in the mouth chart. A dynamic head uses its own pose for each shape instead, which you set in Mouth shapes. See Mouth Chart and Mouth Shapes.

    Face ‣ Mouth ‣ Mouth chart...

    Face ‣ Mouth ‣ Mouth shapes...

Make the Lip Sync

  1. Open the Lip sync box. The box reads the sound that is selected, or the first sound on the timeline when none is selected. Sound id lets you type an id instead of using a sound on the timeline, and Text only makes the shapes from the typed line alone, between the frames you set in Text only: from and Text only: to. See Lip Sync.

    Face ‣ Lip sync...

    Right-click the sound's block ‣ Lip sync to this sound...

  2. Type the line in Words. Exact timing works without it, and typing the line makes the result closer.

  3. Choose how the shapes are timed. Exact runs Rhubarb Lip Sync in the Framez Helper and times each shape to the voice. Line + voice places the shapes of the typed line where the voice is heard. Loudness opens the mouth wider when the voice is louder and needs nothing installed.

  4. If the first result looks too wide or too busy, set Strength and Shortest. Strength scales a dynamic head's mouth, from 0 to 200 %, and Shortest is the fewest frames a shape holds, from 1 to 12, with 2 as the starting value.

  5. Press Make lip sync. The mouth shapes appear as blocks on a Lip sync row under the head's Face row, or under its Mouth row on a classic head. Each block is named by its shape, from X for a resting mouth and A to H for the others.

Check and Correct It

  1. Drag the playhead along the timeline, or play the animation, and watch the mouth against the voice. See Lip Sync Row.

  2. To correct a shape, right-click its block on the Lip sync row and choose another shape. Drag a block to move the change to another frame. The same right-click menu has Delete shape for one block and Delete lip sync for all of them.

  3. To start again with new settings, take the lip sync out of the clip and make it again. The row is greyed when the clip has no lip sync. See Delete Lip Sync.

    Face ‣ Delete lip sync

Save It and Play It in Your Game

  1. Save the animation. A dynamic head's mouth is stored as face control keys, which the game plays with no script.

    File ‣ Save

  2. On a classic head, add the face script to the game once for each game, because the mouth is a Decal that changes image. The Game menu is in the Game data workspace. See Face Swaps in the Game.

    Game ‣ In the game ‣ Face swaps in the game...

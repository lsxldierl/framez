Shortcut List

These are the keys that Framez starts with, grouped as the Keyboard Shortcuts window groups them. They work while a Framez window is active, so click in it first. Any of them can be changed in Keyboard Shortcuts, where you can also start from a set of keys that follows Blender or Moon Animator 2.

Timeline

These keys play the animation and move the playhead and the keys along the timeline.

KeyCommand
SpacePlay / pause
LeftPrevious key
RightNext key
Alt+LeftPrevious frame
Alt+RightNext frame
HomeGo to the start
EndGo to the end
Shift+LeftMove keys 1 frame earlier. The selected keys move, and with no keys selected the selected limb's whole track moves.
Shift+RightMove keys 1 frame later

File

KeyCommand
Ctrl+SSave

Edit

KeyCommand
Ctrl+KMenu search
Ctrl+ZUndo
Ctrl+YRedo
ASelect all
EscSelect none
Del or BackspaceDelete keys, or the selected item of the Modifiers window when no keys are selected

Key

KeyCommand
KInsert key. In the Scene workspace it is Key camera, which keys the selected camera, prop or light.
7Easing
TabLooping

Pose

The slider keys open the slider at the pointer in the mode named, and the key T opens it in the mode you used last.

KeyCommand
RSwitches between Rotate and Move
Ctrl+LWorld space, on or off
OProportional editing, on or off
TOpen the slider at the pointer, in its last mode
Shift+BSlider: Breakdown
Shift+NSlider: Blend to neighbour
Shift+HSlider: Push / relax
Shift+JSlider: Blend to frame
Shift+MSlider: Scale amplitude
Shift+USlider: Blend to default
Shift+OSlider: Time offset

Face

KeyCommand
BBlink here
]Next face here
[Previous face here

Scene

KeyCommand
CLook through camera

View

The number pad keys move the viewport whichever navigation mode is chosen in Preferences.

KeyCommand
PHandles, on or off
F or Num .Frame selected
Num 1View from the front
Ctrl+Num 1View from the back
Num 3View from the right
Ctrl+Num 3View from the left
Num 7View from the top
Num 9View from behind
Num 4, Num 6, Num 8, Num 2Orbit left, right, up and down
Ctrl+Num 4, Ctrl+Num 6, Ctrl+Num 8, Ctrl+Num 2Pan left, right, up and down
Num +Move the view closer
Num -Move the view back
HHide the selected limb
Ctrl+HIsolate, which shows only the selected limb
Alt+HShow all
Ctrl+LeftPrevious bookmark
Ctrl+RightNext bookmark
Ctrl+Page UpPrevious workspace
Ctrl+Page DownNext workspace

Curve Editor

These keys work only while the Curve editor window is the one receiving the key presses, so click in it first. A key given to one of these commands is kept for that window alone.

KeyCommand
ASelect every key on the shown curves
X or DelDelete the selected keys
VHandle type
HomeFrame every curve
F or Num .Frame the selected keys
Shift+BSwap with the buffer curve
OFalloff
Ctrl+GGhost curves
Ctrl+Alt+GClear ghost curves

Modifiers Window

These keys act on the item selected in the Modifiers window when no keys are selected. They are not listed in the Keyboard Shortcuts window and cannot be changed.

KeyCommand
F9Open the values of the selected item again, or of the last item made when none is selected
F2Rename the item
Ctrl+DDuplicate the item
DelDelete the item
Alt+Up, Alt+DownMove the item one place earlier or later

Fixed Keys

These keys only mean something while the tool or list named is in use. They cannot be changed.

KeyCommand
EnterIn a dialog: press its main button, also while typing in a field. Slider open: keep the result. Camera path being drawn: finish the path.
EscCancel or close whatever is open, in any tool
TabSlider open: next mode
WSlider open: switch between world and local
1, 2Slider open: rotation only, position only
X, Y, ZSlider open, or dragging a path key: keep to one axis
O, P, LSlider open: more options
BackspaceCamera path being drawn: remove the last point
Enter, F2, DelIn the animation list: open, rename and delete the selected animation

Keys with the Mouse

These combinations hold a key while you click or drag. They are not commands, so they are not in the Keyboard Shortcuts window.

KeyAction
Shift+click a limbAdds the limb to the selected limbs, or takes it off again
Alt+click on the bodyTurns the selected limb about the point you clicked
Shift while dragging a ring or an arrowDrags more slowly, at the speed set in Precision and Snapping
Ctrl while dragging a ring or an arrowSnaps to the steps set in Precision and Snapping
Alt while dragging a limbPasses the joint limits for that drag

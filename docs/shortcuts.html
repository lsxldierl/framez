Shortcuts

Framez's own keys. They work while a Framez window is active: click in it first. Change any of them in Keyboard shortcuts.

KeysDoes
SpacePlay / stop
← →Previous or next key
Alt+← Alt+→One frame back or forward
Home EndFrame 0 / the last key
Shift+← Shift+→Move the picked keys a frame (with no keys picked, the picked limb's whole track)
KKey the picked limb (in a scene: the picked camera, prop or light)
RRotate / Move
Ctrl+LWorld axes on / off
7The Easing menu
TThe slider by the mouse, in its last mode
Shift+B Shift+N Shift+H Shift+J Shift+M Shift+U Shift+OThe slider in Breakdown, Blend to neighbour, Push / relax, Blend to frame, Scale amplitude, Blend to rest, Time offset
Tab W 1 2 O (slider open)Next mode, World, Turn, Move, Overshoot
TabLoops on / off
OSpread edits on / off
PHandles on / off
CLook through the scene's camera
BBlink here (classic heads)
[ ]Previous / next face at the playhead
H Ctrl+H Alt+HHide the picked limb / show only it / show all
FFrame the picked limb
Num 1 Num 3 Num 7 Num 9Front, right, top and behind views (Ctrl for the other side)
Ctrl+← Ctrl+→Previous / next bookmark
A / EscSelect all / none
DelDelete the picked keys, or the picked item
Ctrl+KFind a command
Ctrl+Page Up Ctrl+Page DownPrevious / next workspace
Ctrl+Z Ctrl+YUndo / redo one run of a tool, or one whole drag of a value
Ctrl+SSave the animation
EnterThe main button of the open dialog, also while typing in a field
EscClose the open dialog, panel or menu
F2 Ctrl+DRename / duplicate the picked item
F9Open the last item's values again
Alt+↑ Alt+↓Move the picked item up or down in the Made order
Shift+click a limbAdd it to the picked limbs, or take it off
Alt+click on the bodyTurn the picked limb about that point
Shift / Ctrl while dragging a ringTurn slowly / snap in steps
Alt while dragging a limbPass the joint limits for that drag
In the Curves window
APick every key on the shown curves
X DeleteDelete the picked keys
VThe handle types
Home / FFrame every curve / the picked keys
Shift+BSwap with the buffer curve

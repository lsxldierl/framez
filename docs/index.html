Framez Manual

Framez is an animation editor for Roblox Studio. It animates R6 and R15 characters, avatars, creatures, skinned meshes and any model with Motor6D joints, and saves animations your game plays. This manual explains every menu, window and tool. Start with Getting Started, or go to the Tutorials for a walkthrough of what you want to make.

Getting Started

Getting StartedThis page opens Framez, shows what is on screen before an animation is open, and takes one animation from its first pose to the asset id your game plays.Installing the Framez HelperFramez works without anything else installed. The Framez Helper is a free Windows program that adds what a Studio plugin cannot do on its own, such as playing video, linking to Blender and reading a webcam. It is needed only for the features that say so.

Interface

The Framez WindowThe Framez window holds the menus, the toolbar, the track list and the timeline. The tools that need more room open as separate windows beside it.WorkspacesA workspace chooses which menus, toolbar buttons, timeline rows and windows the Framez window shows for one kind of job. Changing workspace never changes the animation.Timeline and ToolbarThe toolbar runs along the top of the Framez window. Under it, the track list and the timeline have a row for every limb, and extra rows for events, layers, faces and the other things an animation carries.Working with ToolsEvery tool that makes or changes keys works the same way. You choose it, it runs at once, and you adjust its values afterwards. Most of them also keep their result in the Modifiers window, so you can change it again later.

Menus

FileThe File menu starts, opens, saves and publishes animations, brings animations in from Roblox, Moon Animator 2, Blender and the game, sends them out again, and sets up the rigs you animate. Its rows are the same in every workspace, apart from a few that belong to the Animate or Scene workspace.EditThe Edit menu searches every command, undoes and redoes changes, copies and pastes poses, selects and deletes keys, and opens the settings and keyboard shortcuts. The undo, select and settings rows are the same in every workspace, and the copy and paste rows belong to the Animate workspace.KeyThe Key menu holds everything that works on keys: setting them, changing how the motion travels between them, moving them in time, and cleaning up a finished clip. It shows in the Animate workspace.PoseThe Pose menu holds the tools for posing a rig. They cover how the handles behave, the commands for the selected limb, the slider, mirroring, constraints, physics and the generators. It shows in the Animate workspace. While an additive animation layer is selected, the rows that write whole poses (Snap rig to floor, Mirror, Reset pose, Constraints, Physics and Generate) are greyed out.FaceThe Face menu holds the tools for a character's face: posing it, timing mouth shapes to a voice, acting it to a webcam and switching between face pictures. It shows in the Animate and Scene workspaces.SceneThe Scene menu holds everything that turns one animation into a scene: adding rigs, props, cameras, lights, sounds, effects and subtitles, looking through and cutting between cameras, moving props and cameras along paths, framing the shot, and putting the finished scene in the game. It shows in the Scene workspace.GameThe Game menu holds what a game needs to know about a clip: events a script can hear, screen looks for hits, hit windows, foot contacts and body masks, the previews that show how Roblox will play the clip, and the scripts that carry all of this into your game. It shows in the Game data workspace.ViewThe View menu controls what you see while you work and how the clip plays back. It holds the overlays drawn over the rig, the camera, the open windows, hidden limbs, the reference video, and playback speed and zoom. Nothing in it changes the animation or the saved clip. The Animate workspace shows every row, and the Scene and Game data workspaces show a shorter menu.HelpThe Help menu points to this manual and to the Framez Helper, shows whether the helper is running, lists the other people animating in the same Team Create place, and opens the Scripting window. Studio plugins cannot open a web page, so each link is shown in a box. Click the link, press Ctrl + C to copy it, and paste it into a browser.

Windows

InspectorThe Inspector shows the numbers and settings of whatever is selected and lets you type them. It has up to three pages, chosen with the switch at the top. The first page is named after the selection, such as the selected limb, and is followed by Clip and Posing. The Animate workspace shows all three pages, Scene shows the first two, and Game data shows only Clip.Curve EditorThe Curve editor draws each channel of a limb as a line over time. Change the line and the motion between the keys changes with it. It is for finding why a move looks stiff or wobbly, and for shaping the motion by hand when an easing style is not enough. The window is available in the Animate workspace.ModifiersThe Modifiers window lists the results of the tools you have run on the open animation, so that you can change a result later, turn it off, reorder it, apply it or delete it.PhysicsThe Physics window runs one physics simulation over an animation and writes the result as keys, for a hit, a fall, wind or floating. You build the simulation from bodies, forces and colliders. The Ragdoll window, described at the end of this page, pushes the body at one frame and lets Roblox physics take it from there.Reference VideoThe Reference video window plays a recording beside your animation, locked to the timeline, so you can pose against it. Videos come from the Framez Helper , which reads the videos in your clip folders. A set of image frames works without the helper. The window is available in the Animate workspace.PosesThe Poses window keeps named poses, each shown as a small picture of the rig, and keys them at the playhead with a click. A character that returns to the same few poses, such as a stance, a guard or the wind-up of a swing, can start every clip from one saved pose instead of being posed again by hand. The window is available in the Animate workspace.Camera PreviewThe Camera preview shows what a scene camera sees while the viewport stays on another angle, so you can pose a character from any side and watch the shot at the same time. It opens as a floating window that you can dock or drag to a second screen, and it belongs to the Scene workspace.Subtitle LinesSubtitle lines are the timed dialogue of a scene. The Subtitle lines window lists them and adds many at once from a pasted script or an .srt file, and the subtitle page of the Inspector writes each line and sets how it looks, moves and reads word by word. Both belong to the Scene workspace.Test BenchThe Test Bench tries the open clip the way your game will play it: on your character in a running game, joined to the clips around it, on other body shapes, under a game camera, and against other versions of itself. It is a floating window with one tab for each of these, and a test scene keeps the values of all five.Check AnimationThe Check Animation window lists what will look wrong in your game, each problem at its frame, and gives every problem a button that fixes it. It reads the animation as it will be saved and changes nothing until you press a fix.PreferencesThe Preferences window holds every setting that you set once and keep. They cover how the handles look, how the timeline and viewport behave, what new animations start with, which overlays show, and how Framez saves your work. Settings that change while you pose, such as IK and joint limits, live on the Posing page of the Inspector instead.Keyboard ShortcutsThe Keyboard Shortcuts window lists every command with its key and lets you give any command a key of your own. You can search by name, find out what a key does by pressing it, start from a set of keys that suits you, and save your keys in the place so that everyone working in it can use them.ScriptingThe Scripting window lists the functions that let a script work on the open animation. You can run them from Studio's Command Bar or from a plugin of your own, to open and save animations, read and write keys, run Framez's tools with values from a script, add tools of your own, and react when an animation is opened, saved or changed.

Tutorials

TutorialsEach tutorial takes one goal from start to finish, with the menu path for every step and a link to the reference page of each tool it uses. Follow one from the top, or skip the steps your animation does not need.Making a Combat SkillThis tutorial takes a sword swing from the first blocked pose to a clip the game can play. By the end you have a saved animation that plays once at Action priority, with its hit frames marked for your scripts and its upper body ready to play over a run.Making a Hit with EffectsThis tutorial builds a punch with a trail, sparks, a shockwave and an impact frame, all keyed on the timeline. By the end you have a saved clip whose effects, screen look and hit-stop play in your game every time the clip plays.Making an Idle or FidgetThis tutorial builds a standing idle that breathes and loops without a jump at the seam, and a fidget such as a head scratch or a weapon check that starts from the same stance. By the end you have a looping clip at Idle priority that hands over cleanly to the clips around it.Making a Walk, Run, Strafe or BackpedalThis tutorial makes a locomotion cycle, fixes its feet, marks where each foot lands and checks how it blends with your other cycles. By the end you have a looping clip at Movement priority with planted feet and foot contacts your game can read.Copying a Move from a VideoThis tutorial keys a character's body from the person in a video, such as game footage, a phone video or a dance, and then cleans the result up. By the end you have a first pass of the move on your rig, with smooth motion and feet on the floor, ready to refine by hand.Animating a Dance to MusicThis tutorial keys a dance so that its moves land on the beats of a song. By the end you have a clip whose key poses sit on the music's hits and still moments, ready to loop or to turn into an emote.Making an Emote to SellThis tutorial checks a dance or gesture against Roblox's rules for emotes, fixes whatever Roblox would refuse, and takes it through Roblox's two upload windows. By the end you have an emote that passes the upload check and has been submitted as an Avatar Item.Making an Animation PackThis tutorial gathers a character's idle, walk, run, jump, fall, climb and swim clips into one pack and prepares it either for the Marketplace or for every character in your own game. By the end you have a checked pack, and the steps to sell it or to switch your game over to it.Animating Jumps, Flips and SpinsThis tutorial animates a leap with a flip so that the body flies a true arc, turns the way physics would turn it, and lands without sliding. By the end you have a jump whose air time, height and spin have been checked against Roblox's gravity.Making a Ragdoll Fall or Hit ReactionThis tutorial makes a knockdown, a death fall or a stagger by pushing the body at one frame and letting Roblox physics take over. By the end you have the fall baked into the clip as keys you can change, either in the clip itself or on a layer you can mute to compare.Animating Talking, Reacting and PointingThis tutorial animates a character who looks at what matters, gestures with their arms and moves with weight, framed the way the shot will be seen. By the end you have a performance clip with a saved camera view, a head and an arm aimed at their targets, and gestures you can reuse.Making a CutsceneThis tutorial builds a story moment, a boss introduction or a short film. Several characters and props share one timeline, keyed cameras cut between shots, and lights, sound, subtitles and screen effects are added on top. By the end you have a scene that is saved as one animation and written into your game with a button that plays it.Animating a Grab, Throw or FinisherThis tutorial animates one character acting on another, such as a grab, a throw or a finisher, with both characters keyed on one timeline. At the end you have a scene in which both characters play together, saved and ready to put in your game.Picking Up, Passing and Throwing an ObjectThis tutorial animates a cup, sword, box or hat that a hand picks up, passes to the other hand or to another character, throws or drops, and picks up again. At the end the object follows the character through every change of holder, in Framez and in your game.Animating Faces on a Classic HeadThis tutorial changes the face of a character whose head has a face Decal, with blinks, a shout on the hit and a smirk at the end. At the end the character changes faces as the animation plays, in Framez and in your game.Animating Faces on a Dynamic HeadThis tutorial keys raised brows, a smile, a frown or a shout on a head with FaceControls, such as a Roblox avatar head or a MeshPart head set up for face animation. At the end the face is part of the clip and plays in your game with no script.Setting up Lip SyncThis tutorial times mouth shapes to a voice line, for a short, a cutscene or an NPC's greeting. At the end the character's mouth moves with the voice and the lip sync is saved with the clip.Capturing a Face from a WebcamThis tutorial records your own expressions and speech with a webcam and puts them on the character's face. At the end the take is keyed on the head, which is faster than keying each expression by hand.Testing an Animation in the GameThis tutorial runs the open animation on your own character in Play with the game's priority and fades, then checks it on other body types, through the game's camera and against earlier saves. At the end you have seen how the animation plays in a running game, and not only in Framez.Editing an Animation in BlenderThis tutorial sends the open animation to Blender, edits it with Blender's tools and brings it back into Framez as keys. At the end the edited animation is in Framez, and you know how to keep both programs in step while you work.Starting from an Existing AnimationThis tutorial brings in a catalog animation, an emote, a clip made for another rig, a Mixamo or mocap file, or a Moon Animator 2 project as keys on your rig. At the end you have the motion as ordinary keys, cleaned up and ready to change.Previewing Blends, Layers and Aim OffsetsThis tutorial previews how Roblox's Animation Graphs mix your clips in the game, such as a walk turning into a run by speed, breathing layered over everything, and an upper body that aims where the player looks. At the end you have watched each mix played by Roblox's own Animator on a see-through copy beside the rig, and you have the clips the game's graph needs.Setting up R15, Creature and Custom RigsThis tutorial prepares a rig that is not a plain R6, such as an R15 character, a creature, a door or a skinned mesh with bones, so that every Framez tool works on it. At the end the model opens in Framez and animates like any character.Animating a Lunge on a Rolling FootThis tutorial animates a lunge in which the front foot lands on its heel and flattens while the back foot rolls up onto its toes without sliding. At the end the legs follow the foot controls, and the animation saves as ordinary joint keys.Making a Hand Move with a SwordThis tutorial keeps a second hand on the grip of a sword while the sword swings, lets go of it and takes hold again. At the end the hand follows the sword without a key on every frame.Setting Your Own Keyboard ShortcutsThis tutorial gives any command a key of your own, or switches to the set of keys you know from another tool. At the end the commands you use most are on keys that suit you.

Reference

Shortcut ListThese are the keys that Framez starts with, grouped as the Keyboard Shortcuts window groups them. They work while a Framez window is active, so click in it first. Any of them can be changed in Keyboard Shortcuts , where you can also start from a set of keys that follows Blender or Moon Animator 2.TroubleshootingEach entry names something that looks wrong, says what usually causes it and how to put it right. The entries are grouped by where the problem shows up. Pressing Ctrl + K in Framez and typing a word also finds the tool that a fix names.
